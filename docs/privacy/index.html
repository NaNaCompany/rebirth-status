공개 HTTPS 사이트에는 Google Analytics, Google Tag Manager, Google AdSense와 Cloudflare Web Analytics가 연결됩니다. 이들 서비스가 사용 데이터를 처리할 수 있습니다. 로컬 테스트에서는 네 태그를 실행하지 않습니다.

진행 상태를 지우려면 브라우저 설정에서 이 사이트의 저장 데이터를 삭제하세요. 공유 링크를 연 것만으로 내 저장 결과가 바뀌지 않습니다.

현재 결과의 공유 메뉴 완료, 링크 복사 또는 공유 작성창 열기 후 재추첨 2회를 한 번 받습니다. 실제 전송 여부는 확인하지 않습니다.

공유 작성창과 외부 출처는 각각 해당 서비스의 정책을 따릅니다. 링크 복사는 실제 전송 완료를 뜻하지 않습니다.
